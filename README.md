# BlackDeathCity_Roster

This is a Roster builder and rules reference for **Black Death City** playtest.

Hire warbands, equip fighters, print landscape tarot fighter cards (110 × 75 mm), track battles, and browse the rules catalogue.

Vibe coded using Cursor - mainly Anthropic models

Please provide suggestions

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://127.0.0.1:4173`).

```bash
npm run build
npm run preview
```

## Notes

- Warbands auto-save in the browser; use Export / Load JSON to move them between machines.
