# Black Death City Roster

Roster builder and rules reference for **Black Death City** playtest v1.02.

Hire warbands, equip fighters, print landscape tarot fighter cards (110 × 75 mm), track battles, and browse the rules catalogue.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://127.0.0.1:4173`).

```bash
npm run build
npm run preview
```

## Notes

- Warbands auto-save in the browser; use Export / Load JSON to move them between machines.
- Playtest v1.02 only prints thrall and demon injury tables; standard and beast results are recorded by hand.
